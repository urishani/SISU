# SISU

This repository holds two separate projects.

| Place | Project |
| --- | --- |
| `python/` | Windows desktop app that crawls bookstore sites and fills the catalog Excel file. |
| Repository root | Base44 companion app. Install it here, beside the `python` folder. |

## Python app

See `python/README.md`. Double-click `install.bat` in this folder once. It forwards into `python/`, installs libraries, and puts a **SISU** icon on the desktop.

`start.bat`, `run.bat`, and `commit.bat` here forward to the same files inside `python/`.
